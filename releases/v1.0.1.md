# AgentPay SDK version 1.0.1 release notes

**Release date:** 2026-11-22
**Current version:** v1.0.1

These notes cover what changed in AgentPay SDK `v1.0.1` relative to `v1.0.0`. For the 1.0.0
rewrite, see the [v1.0.0 release notes](./v1.0.0.md).

## Release summary

AgentPay SDK `v1.0.1` is a bug-fix release for MPP payments through the paying proxy. Upgrading
keeps the wallet, limits, and configuration; there are no API or command changes (API `1.1.0`).

## Fixed

- MPP: a persisted session channel no longer blocks one-time charges. The paying proxy keeps one
  channel per origin, so after a Tempo session with a merchant, a charge from the same merchant
  (on Tempo, an EVM network, or Solana, for example with `agentpay proxy start --network
  solana-mainnet`) failed with "no session challenge matches the persisted channel". The
  persisted channel now filters only session challenges; charges are paid as usual and leave the
  channel untouched

## Changed

- the release carries the installer as both `install.sh` and `installer.sh` (the asset name 0.x
  releases used), so `curl -fsSL https://wlfi.sh | sh` installs the latest release

## Upgrading

Run the installer again and restart the services:

```sh
curl -fsSL https://wlfi.sh | sh
agentpay setup
```

`agentpay setup` keeps the existing wallet. See the [changelog](../CHANGELOG.md) for the full list.
